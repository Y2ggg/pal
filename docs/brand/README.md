# PAL 品牌

PAL 的全称为 Personal Ability Library，中文名为“个人能力库”，也有“伙伴”之意。
沉淀经验、打磨能力，让积累服务新的工作，是产品介绍的核心方向。

主标识使用完整小写 pal 字标；独立 p 仅用于 favicon 等紧凑位置。浅色背景使用深松绿
`#233D38`，深色背景使用暖白 `#F4F6EF`。SVG 为本项目原创路径，不依赖外部字体。

- [浅色背景字标](pal-wordmark.svg)
- [深色背景字标](pal-wordmark-light.svg)
- [紧凑图标](pal-icon.svg)

标识与文档遵循仓库 MIT 许可。使用不代表得到作者、Anthropic 或 OpenAI 的官方背书。
运行中的标识内嵌于 `web.py`；改动资产时需同步，并检查明暗主题和紧凑显示。
